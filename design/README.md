# Prototipo de portada v1

Abre `portada-v1.html` en un navegador (con `portada-v1.css` en la misma carpeta).

Es un prototipo visual estático, no la aplicación Angular definitiva. Ningún formulario busca todavía en la API. No contiene nombres, fechas o precios de eventos/artistas inventados.

## Orden de portada
1. Hero con buscador principal.
2. Accesos rápidos.
3. Tres espacios para próximos eventos.
4. Artistas (baile, cante, guitarra, con acceso al resto).
5. Cursos y academias.
6. Revista cultural.
7. Registro profesional (futuro).
